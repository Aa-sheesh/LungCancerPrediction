# Lung Cancer Detection
This web app helps you detect what type of lung cancer you have with 92% accuracy based on the picture of your CT scan.

## Running Locally
1. Open file in text editor
2. Open Terminal and write the following commands-
    ```
        python -m venv
        venv/Scripts/activate
        pip install requirement.txt
        python app.py
    ```
3. Go to the localhost on your web browser and enjoy your app.
