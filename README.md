# Lung Cancer Prediction
Making a project that integrates:
1. **Frontend (React)**
    1. User uploads file/input.
    2. Sends request to backend.
    3. Displays prediction results.

2. **Backend (Node.js/Express)**
    1. Receives request.
    2. Calls ML model API.
    3. Returns response.

3. **ML Model API (Flask/FastAPI)**
    1. Processes data.
    2. Runs ML model.
    3. Returns prediction.
